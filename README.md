# Petal Arena

A complete, dependency-free browser prototype inspired by arena games such as florr.io.

## Run

Open `index.html` in a browser, or start a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Controls

- `WASD` or arrow keys: move
- Survive, collect blue XP orbs, and choose upgrades on level up
